# ADR-0001: Elegir el stack tecnológico

- **Estado:** Propuesto
- **Fecha:** 2026-10-13
- **Autores:** @IvanGonzalezHernandez

## Contexto

Athenea necesita ingerir documentos, generar *embeddings*, guardarlos en una base vectorial, recuperar fragmentos y generar respuestas con un LLM, además de ofrecer una interfaz de chat. El equipo (4 personas) debe acordar el stack antes de empezar a programar.

## Opciones consideradas

Por decidir en equipo. Aspectos a cerrar:

- Lenguaje y framework del backend
- Orquestación RAG (LangChain, LlamaIndex, implementación propia…)
- Base vectorial (Qdrant, Chroma, pgvector…)
- Modelo de *embeddings* y LLM (API externa o modelo local)
- Frontend
